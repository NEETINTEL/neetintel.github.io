G2/G3 EAM Structure

G2・G3 EAMの構造

IndexG4 EAM Structure
目次G4 EAMの構造

Many long Group 2 messages end with one 15-character block read two to four times. Group 3's structured messages are all put together the same way: the 2-character prefix, an opening block that doesn't repeat, then blocks of 5, 14 or 23 characters in which some slots hold the same letter in every block, then a short tail. Long G2 messages use 5-character blocks too, three at a time, and a G3 32 aired within a few minutes of one keeps the same slots.

長い第2群のメッセージの多くは、15文字のブロックを2〜4回並べて終わります。第3群の構造のあるメッセージは、どれも同じ組み立て方です。2文字の接頭辞、繰り返さない最初のブロック、5文字・14文字・23文字のどれかのブロックの連なり（いくつかの枠はどのブロックでも同じ文字）、そして短い末尾です。長いG2メッセージにも5文字のブロックが3つずつ現れ、その数分以内に放送されたG3の32文字は同じ枠を保ちます。

Fifteen-character blocks, Group 2 74 G2 messages, all since the break

15文字のブロック（第2群） G2 74件、すべて切り替わり以降

Long G2 messages that end with one 15-character block written out two to four times back to back, the copies agreeing in most slots, then one character. The head in front stretches with the message, so the copies always sit at the end. By chance you would expect about none in the whole corpus. Rows are in date order, lined up on the first copy. QH-72 (261008) is the one exception: built like the 75s that read the block three times, with 14 other characters where the middle copy would be, and drawn that way.

15文字のブロックを2〜4回続けて並べて終わる、長いG2メッセージです。どの回もほとんどの枠が同じ文字で、そのあとに1文字つきます。前の頭部がメッセージの長さに合わせて伸び縮みするので、ブロックはいつも末尾に来ます。偶然なら、記録全体でもほぼ0件と見込まれます。行は日付順で、1回目のブロックでそろえています。例外はQH-72（261008）の1件だけです。ブロックを3回並べる75文字と同じ組み立てですが、2回目のブロックの位置に別の14文字が入っています。図もそのようにそろえています。

Every G3 message where three or more 5-character blocks follow one another, each sharing 3 or more letters, in the same slots, with the next (looked for from every starting character).
