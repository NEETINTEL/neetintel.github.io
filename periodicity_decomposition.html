Why P=44 doesn’t dominate here: This approach pools all messages regardless of prefix. The 44-char periodicity is prefix-specific — messages with the same prefix share the same block structure, but different prefixes may be phase-shifted relative to each other. When pooled, one prefix’s structured positions overlap with another’s random positions, washing out the signal. The pairwise analysis (Section 1) avoids this by only comparing messages within the same prefix, where P=44 is clearly dominant.

6. Sub-periodicity within the 44-char block

Does the 44-position entropy profile itself have internal periodicity? Tests sub-periods that divide 44 (2, 4, 11, 22) by computing autocorrelation of the entropy sequence at each lag.

Autocorrelation thresholds: > 0.5 = Strong, > 0.25 = Moderate, > 0.1 = Weak, ≤ 0.1 = None. Strong sub-periodicity at, say, period 11 would mean the 44-char block is composed of four 11-char sub-blocks with similar structure.

7. Statistical validation

Permutation test

Shuffled the position-to-character mapping 1,000 times and recomputed entropy variance at period 44 each time. The observed variance (0.00065) exceeded 1,000 of 1,000 permutations.
