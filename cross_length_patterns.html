⚠ Rough tool — use with caution. This page is a pain to manage. It re-runs the heatmap detection for every length, and lining lengths up means picking an anchor — the start or the end — that the messages themselves don’t give you. Its main value is showing that some position relationships, like 21 = 24, hold across a lot of different message structures. If something here looks off, check it against the heatmap page itself.

⚠ 試作ツール：注意して使ってください。このページは管理が大変です。長さごとにヒートマップの検出をやり直していて、長さを並べるには基準（先頭か末尾か）を選ぶ必要がありますが、それはメッセージ自体からは分かりません。このページの一番の価値は、21 = 24のような位置の関係が、さまざまなメッセージ構成にまたがって成り立つことを示す点です。おかしく見えるところがあれば、ヒートマップのページ自体で確かめてください。

Each heatmap page tests one message length on its own. This page stacks them: one row per length, positions running across, as on the heatmap pages. A coloured square is part of a pattern that passes at that length and, at the same place, at two or more other lengths of the same group, so a pattern that holds across lengths stands as a column. A quad shows as four squares side by side, X??X as two squares three apart.

ヒートマップのページは、メッセージの長さごとに別々に検定しています。このページはそれを積み重ねたものです。1行が1種類の長さで、ヒートマップのページと同じく位置は横に並びます。色の付いたマスは、その長さで通り、同じグループのほかの2種類以上の長さでも同じ場所で通ったパターンの一部です。長さをまたいで成り立つパターンは縦の列になります。4文字の連続は横に並んだ4つのマス、X??Xは3つ離れた2つのマスとして表示されます。

The grid is as wide as the group’s longest message. A shorter message opens a gap (the dashed line) so that its start lines up on the left and its end on the right, the way a shorter message lines up with a longer one that has extra blocks inside it. The gap goes after the patterns counted from the start and before the ones counted from the end. The ruler above counts from the start; the one below from the end, where −1 is the last character.

表の幅は、そのグループで一番長いメッセージに合わせています。短いメッセージは途中にギャップ（破線）を入れて、先頭を左に、末尾を右に揃えます。中にブロックが多く入った長いメッセージに短いメッセージを揃えるのと同じ考え方です。ギャップは、先頭から数えるパターンの後ろ、末尾から数えるパターンの前に入れています。上の目盛りは先頭から、下の目盛りは末尾から数えた位置です（−1が最後の文字）。

A run is listed once, as its run zone (the stretch where the group’s runs line up), not as the pairs inside it. Neighbouring pairs the same distance apart are one entry: 25–48 = 40–63 means positions 25 to 48 repeat 15 later. Hover over a square or a table row to pick out one pattern; click a square to open that length’s heatmap.

連続は、その中のペアとしてではなく、連続ゾーン（グループの連続が揃う区間）として1回だけ載せています。同じ間隔で隣り合うペアは1つにまとめています。25–48 = 40–63は、25〜48文字目が15文字後にもう一度現れるという意味です。マスか表の行にカーソルを合わせると、そのパターンだけが目立ちます。マスをクリックすると、その長さのヒートマップを開きます。

Some of this lines up by chance. To check, each page’s patterns were moved to a random place in the message, wrapping round at the end, 500 times. Patterns that line up at only two lengths came up about as often that way as they do here, so they are left out. In each table, “by chance” is how many patterns spanning at least as many lengths the random placements average. Where that is 1 or more, chance alone would give one like it: its squares are outlines and its row is dim.

偶然に揃う部分もあります。そこで、各ページのパターンをメッセージ内のランダムな位置に（末尾で先頭に戻して）移す作業を500回行いました。2種類の長さでしか揃わないパターンは、そうしても実際と同じくらい現れたので除いています。各表の「偶然」は、ランダムな配置で、それ以上の種類の長さにまたがるパターンが平均いくつできるかです。1以上なら偶然だけでも同じようなものができるので、マスは枠だけにし、表の行は薄く表示しています。
