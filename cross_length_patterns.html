⚠ Rough Tool — Use With Caution
This page is complex, difficult to troubleshoot, and doesn’t quite work the way I figured it would. Its main value is showing that certain position relationships — like the 21,24 pairing — show up across many different message structures. However, it can over-index some of the blocks (e.g. the "AAAA"s) and trying to make it not do that causes problems. It also returns at least a few total nonsense pairings for reasons beyond earthly comprehension. It's a semi-useful tool with a few solid examples, but don’t get too invested in any instances where this page says a pair exists and then you look into it and it literally doesn't exist. I could troubleshoot it some more to iron those out but this page is not something I want to sink a lot of time into right now.
